# Família Extrajudicial OS — Marketplace

Preparação documental pelo advogado dos interessados em divórcio, união estável e inventário extrajudiciais, com limites normativos explícitos.

## Instalação no Cowork

No Claude Desktop, abra a área de plugins do Cowork, escolha adicionar um marketplace e informe `https://github.com/sbroggioadv/familia-extrajudicial-os-marketplace`. Instale **familia-extrajudicial-os**, abra uma conversa e execute `/familia-extrajudicial-install` para configurar; use `/familia-extrajudicial-master` para conduzir o trabalho.

O repositório foi preparado localmente; a URL ficará disponível após a publicação pelo titular.

## Escopo e limites

O plugin oferece 32 skills e 14 comandos. O advogado revisa os documentos e as fontes antes do uso. O plugin não pratica atos da serventia nem substitui decisões de tabeliães, registradores, Ministério Público ou Poder Judiciário. Consulte o [README do plugin](familia-extrajudicial-os/README.md).
